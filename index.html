Hollow Knight: Catch the Fleas

About the Project

A fan-made interactive game inspired by Hollow Knight: Silksong, where you play as Hornet and race to catch escaped fleas across hand-crafted environments. Built with C++ and OpenGL, it features custom sprite rendering, real-time collision detection, and animated 3D assets modelled in Blender. Developed as part of a computer graphics course, focusing on real-time rendering techniques and interactive gameplay mechanics.

Leaf it To Me

▶ Play on itch.io

About the Project

A cozy first-person leaf-raking game built in Unity 6 with URP. Rake, blow, and hand-pick leaves across a golden-hour garden, sell them at the bin, repair broken vents, and upgrade your tools to clear every last corner. Features a full economy, save system, tutorial, and win condition — a complete, playable portfolio demo. Free to download on itch.io.
